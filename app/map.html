      There’s no public live meter reading for each power station, so each one is modelled. Every unit tells the grid operator in advance what it plans to generate (its Physical Notification), and the operator’s instructions to turn up or down (Bid-Offer Acceptances) override that plan. Both come from Elexon.

      Those estimates are then scaled, fuel by fuel, so they add up to Elexon’s measured total for the same five minutes. The totals here therefore match the overview, while each station’s figure is a close estimate rather than a meter reading.

        How these figures are made

        Elexon publishes measured output for each fuel type nationally every five minutes, but not for individual power stations in real time. So each station is modelled from two Elexon datasets: the Physical Notification each unit submits an hour ahead saying what it plans to generate, and the Bid-Offer Acceptances where the grid operator (NESO) tells a unit to change that plan.

        The modelled figures for each fuel are scaled to Elexon’s measured total for the same five minutes, so the map and this page agree with the overview. The scale factor for each fuel is shown in the type table; values near 1 mean the plans matched reality closely.
